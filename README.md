# 📖 Personal Diary

A simple, beautiful, and private web-based personal diary to document your thoughts, feelings, and memories. This project is built using purely client-side technologies, meaning your data stays right in your browser.

## ✨ Features

-   **Write Entries**: Easily record your daily thoughts with a title and date.
-   **View Entries**: A dedicated page to see all your past memories in a clean list.
-   **Delete Entries**: Remove entries you no longer wish to keep.
-   **Local Persistence**: Uses browser `localStorage` to save your data, so it persists even after refreshing or closing the browser.
-   **Responsive Design**: A clean and simple UI that works well across different screen sizes.
-   **About Page**: Information about the goal of the Personal Diary.

## 🚀 How to Use

Since this is a client-side application, there's no installation or setup required.

1.  Clone or download this repository to your local machine.
2.  Open `index.html` in any modern web browser.
3.  Navigate through the menu to start writing your diary!

## 🛠️ Technologies Used

-   **HTML5**: For the structure of the web pages.
-   **CSS3**: For styling and layout (vibrant colors and clean design).
-   **JavaScript (ES6+)**: For logic, handling entries, and local storage management.

## 📁 File Structure

-   `index.html`: The home page welcoming the user.
-   `write.html`: The interface for creating new diary entries.
-   `entries.html`: The page to view and manage saved entries.
-   `about.html`: Information about the application.
-   `style.css`: The stylesheet for the entire project.
-   `script.js`: The JavaScript logic for saving, loading, and deleting entries.
